# 幾何公差ドリル

JIS B 0021 を主軸に、幾何公差（GD&T）の記号・データム・位置度・最大実体公差方式などを、スマートフォンで毎日少しずつ学べる問題集です。ISO 1101:2017・ASME Y14.5-2018 との違いも「規格の違い」の分野で扱います。ブラウザで使える Web 版と、Android アプリ（APK）があります。

**[▶ Web 版を開く](https://kotaooka.github.io/gdt-drill/)**　｜　**[⬇ Android アプリ（APK）をダウンロード](https://github.com/kotaooka/gdt-drill/releases/latest)**

> 試作版です。内容は順次追加・見直しします。

## 特長

- **図を見て解く問題**：公差記入枠・データム記号・部品図・公差域の図を、問題文と一緒に表示します（図はすべて描き起こし）。
- **毎回数値が変わる計算問題**：位置度の偏差（3次元測定機の座標から）、Ⓜ のボーナス公差、ゼロ幾何公差の判定と書き換え、実効寸法と機能ゲージ、円周振れ・全振れ、定盤での平行度、輪郭度の判定、普通幾何公差（JIS B 0419）など。
- **測定・検査・検具**：3次元測定機の座標系、定盤とダイヤルゲージ、真円度測定機、標準温度、測定の不確かさ、機能ゲージ、限界ゲージ、検査治具。
- **公差記入枠を組み立てる問題**：「○○を規制したい」という要求から、記号・公差値（φ・Ⓜ の有無）・データムの順を選んで枠を完成させます。
- **複数段の公差記入枠**：ASME の複合位置度（記号を1つにした2段の枠）と、単一の枠を重ねた指示の違いを、組み立て問題でも練習できます。
- **図面の誤りを見つける問題（検図）**：φ・データム・Ⓜ の付け方、データムの順序、共通データム、± 寸法との併用などの誤りを見つけて直します。
- **図面を読む総合問題**：1枚の図について、穴埋め・正誤で続けて答えます。
- **合否を判定する問題**：測定値（座標・ダイヤルゲージの読み・振れの読み）から、合格か不合格かをタップで答えます。
- **動く図**：スライダーを動かして、Ⓜ のボーナス公差（RFS・Ⓜ・ゼロ幾何公差の比較）、位置度の四角と円の公差域、公差の積み上げを確かめられます（資料タブ）。
- **記号フラッシュ**：幾何特性の記号と名前を、時間を競って答えるミニゲームです。
- **実績（バッジ）**：連続学習・実力診断・記入枠の組み立てなどの節目でバッジがもらえます。
- **組付け・工程管理**：実効寸法による最悪のすき間、公差の積み上げ（最悪値法・RSS）、データムシフト、片側の特性の工程能力、測定の不確かさを考えた合否判定。
- **学習ロード**：図面の文法から最大実体公差方式・測定と検査・海外の図面まで、9章のストーリーで進めます。
- **実力診断**：全分野から約40問を時間制限なしで解き、分野・項目ごとの正答率と弱い項目を確認できます。結果から、弱い項目やまちがえた問題をそのまま演習できます。前回の診断との比較も表示し、結果を1枚の画像として保存できます（教育の記録や報告用）。出題コードを使うと、複数の人が同じ問題で受けられます。
- **記入枠を読む**：公差記入枠を組むと、指示の意味・公差域・データムの役割・Ⓜ のボーナス・測り方を表示し、φ・データム・Ⓜ の不適切な付け方を指摘します（資料タブ）。
- **検索**：右上の虫めがねから、問題・解説・早見表・公式・関連規格を言葉で探せます（MMC・CMM などの略語も可）。
- **実務のケース問題**：検査成績書の判定・記録の確認、図面指示の不足で不良が通る例（寸法公差だけのピン、データムのない位置度・輪郭度）。
- **問題の種類**：知識・計算・図面を読む・記入枠を組む・検図の5種類で絞り込めます。
- **間隔をあけた復習・早見表**：記号一覧、付加記号、普通幾何公差の表、JIS／ISO／ASME の違いの表、まちがえやすい組み合わせの比較表、公式集。

## 使い方

**Web 版**：上のリンクを開くだけです。ホーム画面に追加すると、オフラインでも起動できます。

**Android**：[Releases の最新版](https://github.com/kotaooka/gdt-drill/releases/latest) の「Assets」から **gdt-drill.apk** をダウンロードし、インストールします（提供元不明のアプリの許可が必要です）。新しい版を同じ手順で入れると上書きされ、解答記録は引き継がれます。

解答記録は端末の中だけに保存されます（外部に送信しません）。

## 誤りの報告

解説の下の「誤りを報告」から、[Issues](https://github.com/kotaooka/gdt-drill/issues) に送れます。

## 注意

- 個人が作成した非公式の学習教材です。日本規格協会・ISO・ASME とは関係ありません。
- 問題・解説・図はすべてオリジナルで、規格の本文や図は転載していません。規格の内容は、必ず原典（規格票）で確認してください。
